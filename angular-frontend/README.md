# Ultimate Utility — Angular PoC

This branch contains a minimal Angular v21 proof-of-concept (PoC) migration of the React project. It includes:

- Angular workspace scaffold (minimal)
- Tailwind integration
- PrimeNG placeholders (primeng installed) — adapters to be fleshed out
- Lazy-loaded Portal module with Shell, Dashboard, Tasks, Calendar pages (representative)
- SharedModule with a simple Button component and a DataService example

How to run locally:
1. cd angular-frontend
2. npm ci
3. npm run start

Notes:
- This is a PoC and not a full 1:1 conversion of all pages/components. Use this branch as the migration starting point. The repo's original React code remains in the main branch.
